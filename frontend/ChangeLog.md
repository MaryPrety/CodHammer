## [0.8.25] - 2025

### Добавлено

#### Аутентификация и регистрация
- Регистрация новых пользователей с полной информацией (имя, фамилия, email, телефон, учебная группа, год поступления, образовательное учреждение, направление обучения, возраст)
- Авторизация по email или телефону
- JWT токены для безопасной аутентификации
- Автоматическое сохранение сессии пользователя

#### Профиль пользователя
- Просмотр профиля с полной информацией о пользователе
- Редактирование профиля (личные данные, интересы)
- Автоматический расчет курса и семестра на основе года поступления
- Система баллов (points) для отслеживания активности
- Статистика пользователя:
  - Опросы (polls)
  - Хакатоны (hackathons)
  - Посещаемость (attendance)
  - Конференции (conferences)
  - Ставки (bet)
- Недельная активность пользователя по дням недели
- Визуализация статистики с помощью графиков и диаграмм

#### Календарь событий
- Просмотр всех событий в календарном виде
- Фильтрация событий по датам
- Детальная информация о событиях (название, описание, тип, даты)
- Поддержка различных типов событий (Conference, Hackathon и др.)
- При завершении события календарь его не отображает, а переводит его в архив и удаляет его через некоторое время. 

#### Опросы (Quiz/Surveys)
- Просмотр списка активных опросов
- Отображение информации об опросах (название, описание, изображение, дата окончания)
- Прохождение опросов с различными типами вопросов:
  - Выбор одного варианта
  - Множественный выбор
- Защита от повторного прохождения одного опроса
- Автоматическое начисление баллов за прохождение опросов
- Отображение количества прошедших опрос пользователей
- Многоязычная поддержка названий опросов (русский/английский)

#### Ставки (Bet)
- Просмотр доступных ставок
- Участие в ставках на технологические соревнования
- Отслеживание результатов ставок

#### Магазин (Shop)
- Просмотр каталога товаров с изображениями
- Фильтрация товаров по категориям:
  - MIREA
  - Robots Battle
  - RTC MIREA
  - IPTIP
- Отображение цены и описания товаров
- История покупок (Story) с деталями заказов

#### Административные функции
- Создание и управление опросами (только для администраторов)
- Установка количества баллов за опросы
- Просмотр статистики опросов с детальной аналитикой:
  - Количество ответов на каждый вопрос
  - Процентное распределение ответов
- Создание и управление событиями (только для администраторов)
- Создание и управление товарами (только для администраторов)

#### Технические улучшения
- REST API на Go с использованием PostgreSQL
- JWT аутентификация для безопасного доступа
- CORS поддержка для работы с frontend
- Автоматическое создание таблиц базы данных при первом запуске
- Многоязычность (русский и английский языки)
- Локализация интерфейса
- Адаптивный дизайн для мобильных устройств
- Визуализация данных с помощью графиков (fl_chart, pie_chart)
- Интеграция календаря (table_calendar) для отображения событий

#### Инфраструктура
- Docker Compose конфигурация для легкого развертывания
- PostgreSQL база данных
- Redis поддержка (настроена в docker-compose)
- Структурированная архитектура проекта (backend/frontend)
