# CodHammer: Модель монетизации

Презентация о ценности, финансовой модели и стратегии монетизации платформы CodHammer для студентов, университетов и организаторов мероприятий.

## Ценность для клиента

### Студенты

- Мотивация к активности
- Призы за участие

### Университеты

- Учёт и поощрение активности
- Вовлечённость

### Организаторы

- Рост аудитории
- Вовлечённость

### Ценность

- Геймификация
- Ставки на события
- Эксклюзивный мерч

## Модель монетизации

### Партнёрская реклама

IT-компании платят за размещение рекламы (100 000 руб./мес).

### Спонсорство мероприятий

Организаторы платят 200 000 руб. за интеграцию.

### Продажа Merch Points

Баллы за деньги (1 балл = 1 рубль).

### Разработка диагностических инструментов

Выполнение по заказу университета инструментов анализа студентов с последующей годовой подпиской.

## Ценовая политика

| Activity Points | Бесплатно | За активность |
| :-- | :-- | :-- |
| Merch Points | 1 руб./балл | Доступ к мерчу |
| Партнёрская реклама | 50-150 тыс./мес | Реклама в приложении |
| Спонсорство | 100-300 тыс. | Брендинг мероприятий |

## Гипотезы для тестирования

1. Покупка баллов
   - Студенты будут покупать Merch Points.

2. Спонсорство событий
   - Организаторы платят за интеграцию.

3. Реклама IT-компаний
   - Компании платят при росте аудитории.

4. Работа без зарплат
   - Команда согласна ждать выплат.

## Условия выплат разработчикам

### Только после дохода

Выплаты команде - после привлечения партнёров.

### Первая выплата месяц 2

Доход превышает 300 000 руб.

### Минимизация рисков

Выплаты зависят от успеха.

## План действий

### Месяц 1-2

- Запуск MVP
- Реклама в сообществах
- Тест продаж баллов
- Первые партнёры

### Месяц 3-6

- Расширение базы
- Рекламные стенды
- Выплаты команде
