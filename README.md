## Основные источники дохода

1. **Партнёрская реклама**
- Размещение рекламы от IT-компаний и других организаций, ориентированных на студенческую аудиторию
- Таргетированная реклама через официальные каналы университетов (Telegram, ВКонтакте)
- Бюджет: 100,000 - 300,000 рублей в месяц

2. **Спонсорство мероприятий**
- Поддержка и маркетинг студенческих мероприятий
- Привлечение спонсоров для различных событий платформы

3. **Продажа мерча**
- Брендированная продукция МИРЭА
- Сувенирная продукция от "Битвы роботов"
- Возможность обмена баллов на эксклюзивные призы

## Ускорение выхода на самоокупаемость

1. **Оптимизация расходов**
- Использование студенческой команды разработки
- Минимизация затрат на заработную плату

2. **Партнёрства с университетами**
- Пилотный запуск платформы в учебных заведениях
- Получение обратной связи для улучшения сервиса

3. **Государственная поддержка**
- Участие в программах поддержки инновационных стартапов
- Привлечение грантов для развития проекта
