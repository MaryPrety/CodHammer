# CodHammer

CodHammer — это мобильное приложение для студентов, разработанное на Flutter с backend на Go. Приложение предоставляет функционал для управления событиями, прохождения опросов, участия в ставках, просмотра профиля и покупки товаров в магазине.

## Архитектура проекта

Проект состоит из двух основных компонентов:

- **Backend** (`backend/`) — REST API сервер на Go с использованием PostgreSQL
- **Frontend** (`frontend/`) — мобильное приложение на Flutter

## Технологический стек

### Backend
- **Язык**: Go 1.23.6
- **База данных**: PostgreSQL 15
- **Аутентификация**: JWT (JSON Web Tokens)
- **HTTP роутер**: Gorilla Mux
- **Хеширование паролей**: bcrypt

### Frontend
- **Фреймворк**: Flutter (SDK >=3.0.0)
- **Состояние**: Provider
- **HTTP клиент**: http
- **Локальное хранилище**: SharedPreferences
- **Локализация**: flutter_localizations (русский, английский)
- **Дополнительные библиотеки**: 
  - table_calendar — календарь событий
  - fl_chart — графики и диаграммы
  - video_player — воспроизведение видео
  - pie_chart — круговые диаграммы

## Функционал для клиента

### 1. Аутентификация и регистрация
- **Регистрация пользователя** с полями:
  - Имя и фамилия
  - Email и телефон
  - Пароль
  - Учебная группа
  - Год поступления
  - Образовательное учреждение
  - Направление обучения
  - Возраст
- **Авторизация** по email или телефону
- **JWT токены** для безопасной аутентификации
- **Автоматическое сохранение сессии** пользователя

### 2. Профиль пользователя
- **Просмотр профиля** с информацией:
  - Личные данные (имя, фамилия, email, телефон, возраст)
  - Учебная информация (группа, курс, семестр, год поступления)
  - Образовательное учреждение и направление
  - Количество баллов (points)
  - Статус аккаунта
- **Редактирование профиля**:
  - Обновление личных данных
  - Управление интересами (список интересов)
- **Статистика пользователя**:
  - Опросы (polls)
  - Хакатоны (hackathons)
  - Посещаемость (attendance)
  - Конференции (conferences)
  - Ставки (bet)
- **Недельная активность** — статистика активности по дням недели
- **Автоматический расчет курса и семестра** на основе года поступления

### 3. Календарь событий
- **Просмотр всех событий** в календарном виде
- **Фильтрация событий** по датам
- **Детальная информация** о каждом событии:
  - Название и описание
  - Тип события (Conference, Hackathon и др.)
  - Дата начала и окончания
  - Создатель события
- **Создание событий** (только для администраторов)

### 4. Опросы (Quiz/Surveys)
- **Просмотр активных опросов**:
  - Список всех доступных опросов
  - Название и описание опроса
  - Изображение опроса (если есть)
  - Дата окончания опроса
  - Количество прошедших опрос пользователей
- **Прохождение опросов**:
  - Поддержка различных типов вопросов (выбор одного варианта, множественный выбор)
  - Валидация ответов
  - Защита от повторного прохождения одного опроса
- **Начисление баллов** за прохождение опросов:
  - Автоматическое начисление баллов после прохождения
  - Настраиваемое количество баллов за каждый опрос (для администраторов)
- **Статистика опросов** (только для администраторов):
  - Количество ответов на каждый вопрос
  - Процентное распределение ответов
  - Детальная статистика по каждому вопросу

### 5. Ставки (Bet)
- **Просмотр доступных ставок**
- **Участие в ставках**
- **Отслеживание результатов ставок**

### 6. Магазин (Shop)
- **Просмотр каталога товаров**:
  - Название и описание товара
  - Цена товара
  - Изображения товаров
- **Фильтрация товаров** по категориям:
  - MIREA
  - Robots Battle
  - RTC MIREA
  - IPTIP
- **История покупок** (Story):
  - Просмотр истории заказов
  - Детали покупок

### 7. Дополнительные возможности
- **Многоязычность**: поддержка русского и английского языков
- **Темная/светлая тема**: настраиваемый интерфейс
- **Визуализация данных**: графики и диаграммы для статистики
- **Навигация**: удобная нижняя панель навигации между разделами

## API Endpoints

### Аутентификация
- `POST /register` — регистрация нового пользователя
- `POST /login` — авторизация пользователя
- `GET /health` — проверка работоспособности сервера и БД

### Пользователи
- `GET /users` — получение списка всех пользователей (требует авторизации)
- `GET /current-user` — получение данных текущего пользователя
- `GET /profile` — получение профиля текущего пользователя
- `POST /profile-update` — обновление профиля пользователя

### Опросы
- `GET /surveys` — получение списка активных опросов
- `POST /createsurvey` — создание нового опроса (только для администраторов)
- `POST /submitsurvey` — прохождение опроса
- `GET /surveys/{id}/statistics` — получение статистики опроса (только для администраторов)
- `POST /set-survey-points` — установка баллов за опрос (только для администраторов)

### События
- `GET /events` — получение списка всех событий
- `POST /createevent` — создание события (только для администраторов)
- `PUT /events/{id}` — обновление события (только для администраторов)
- `DELETE /events/{id}` — удаление события (только для администраторов)

### Товары
- `GET /products` — получение списка всех товаров
- `POST /createproduct` — создание товара (только для администраторов)
- `PUT /products/{id}` — обновление товара (только для администраторов)
- `DELETE /products/{id}` — удаление товара (только для администраторов)

## База данных

Проект использует PostgreSQL со следующими основными таблицами:

- `users` — пользователи системы
- `surveys` — опросы
- `user_responses` — ответы пользователей на опросы
- `survey_points` — настройки баллов за опросы
- `events` — события
- `products` — товары
- `user_interests` — интересы пользователей
- `user_stats` — статистика пользователей
- `weekly_activity` — недельная активность пользователей

## Роли пользователей

- **Student** (студент) — обычный пользователь с доступом к базовому функционалу
- **Admin** (администратор) — расширенные права для управления опросами, событиями и товарами

## Безопасность

- Пароли хешируются с использованием bcrypt
- JWT токены для аутентификации
- CORS настроен для работы с frontend
- Валидация входных данных на сервере
- Защита от повторного прохождения опросов

## Дополнительная информация

- Приложение поддерживает локализацию (русский и английский языки)
- Система автоматически рассчитывает курс и семестр студента на основе года поступления
- Статистика пользователя обновляется при различных действиях (прохождение опросов, участие в событиях и т.д.)
- Backend автоматически создает необходимые таблицы в базе данных при первом запуске
